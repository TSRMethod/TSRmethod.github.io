## Overview

SSE-TSR integrates secondary structure information with the Triangular Spatial
Relationship (TSR) framework. Traditional TSR creates triangles between Cα
atoms in protein structures and assigns unique integer keys based on geometric
features such as distance, angle and atom type. SSE-TSR builds on this by
categorising TSR keys into 18 distinct groups based on secondary structural
elements — alpha helices, beta sheets and coils.

This offers a more detailed representation of protein structures and improves
classification accuracy. By considering not only the geometric arrangement of
Cα atoms but also secondary structure, SSE-TSR gives a richer characterisation
of proteins. This dual-level representation supports efficient, alignment-free
comparison, capturing both high-level structural features and subtle
substructural variation.

The method has been tested on two major protein datasets, showing strong
performance in classifying proteins by structure.

## Installation

Clone the repository:

```bash
git clone https://github.com/pooryakhajouie/TSR-Package.git
cd TSR-Package
```

Create a virtual environment and activate it:

```bash
python3 -m venv tsrenv
source tsrenv/bin/activate   # macOS / Linux
tsrenv\Scripts\activate      # Windows
```

Install the package:

```bash
pip install .
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

SSE-TSR has its own entry point, `SSETSR()`, rather than an argument to
`TSR()`.

### Retrieve PDB files

```python
from tsr_package import PDB_DL

# Retrieve PDB files for the specified PDB IDs
pdb_ids = ["1GTA", "1GTB", "1LBE"]
PDB_DL(pdb_ids, 'Dataset')
```

This downloads the PDB files into the specified `Dataset/` directory, which is
also the default if no directory is given.

### Generate keys with secondary structure information

```python
from tsr_package import SSETSR

# Define the directory where PDB files are stored
data_dir = "Dataset"
input_files = ["1GTA", "1GTB", "1LBE"]
chain = ["A", "A", "A"]        # specify chains for each PDB file
output_option = "keys"          # choose 'keys', 'triplets', or 'both'

# Process protein data to generate key files
SSETSR(data_dir, input_files, chain=chain, output_option=output_option)
```

Protein chains are case-sensitive and must match the chain IDs in the PDB file.

> `SSETSR()` accepts the same optional arguments as `TSR()`, so mirror-image
> discrimination, amino acid grouping and size filtering can be combined with
> secondary structure keys.

### Using a CSV file as input

```python
from tsr_package import SSETSR

# Define the directory and CSV file path
data_dir = "Dataset"
csv_file = "sample_details.csv"

# Process the CSV input
SSETSR(data_dir, csv_file, output_option="keys")
```

The CSV file should have two columns, one for the protein IDs and one for the
corresponding chains:

| protein | chain |
| --- | --- |
| 1GTA | A |
| 1GTB | A |
| 1LBE | A |
